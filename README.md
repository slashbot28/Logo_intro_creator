# Logo & Intro Creator 🎨✨

Een interactieve studio voor het ontwerpen van gepersonaliseerde **logo-badges en kinetische intro-animaties** met vloeiende typografie en dynamische effecten.

---

## 🚀 Snelle Start

- **Online Live Demo**: [https://logo-intro-creator.web.app](https://logo-intro-creator.web.app)
- **Lokaal**: Open `index.html` in je browser (dubbelklikken in Verkenner of openen in Chrome / Edge).

---

## ✨ Functies & Instellingen

- **Logo Badge**: 
  - Regel 1 (Boven): Vul een eigen naam, merk of voornaam in
  - Regel 2 (Onder): Vul een achternaam, subtitel of categorie in
  - Vormen: *Afgeschuind*, *Cirkel*, *Squircle*, *Hexagon*
  - Stijlen: *Tekst Logo*, *Arena Ringen*, *Monogram*
- **Hoofdnaam**: Aanpasbare display typografie met dynamische hover micro-animaties
- **Slogan Cyclus**: Aanpasbare wisselende woorden (bijv. *IMAGINING, DESIGNING, GROWING, CONNECTING, REIMAGINING*)
- **Visuele Sfeer**: *3D Koepel*, *Deeltjes* of *Minimalistisch*
- **Video Opname**: Neem de intro-animatie direct op als WebM-videobestand
- **Exporteren**: Standalone `.html` intro-pagina, vector `.svg` logo en embed code
